# Knowledge base (editable source records)

Everything in this folder is **hand-editable source data** and is committed to Git.
Generated artefacts (the vector index) live in `.cache/kb-index/` and are rebuilt automatically.

| File | What it is |
|---|---|
| `sources.json` | One entry per price source (title, reference, `source_type`, dates). |
| `pricing_records_demo.csv` | **Synthetic** demonstration prices (`data_quality=synthetic_demo`). 57 records. |
| `pricing_records_sourced.csv` | Real, attributable prices. **Currently empty (header only).** |
| `scope.json` | Declared vehicle / region coverage of the pricing data. |
| `indian_vehicles.json` | Vehicle catalog for the UI selector (47 models, 13 makes, 2022–2026). Generated by `python -m src.kb.generate_catalog`; validated by `python -m src.kb.vehicles --validate`. |

> **All current prices are synthetic.** Every result that uses them is labelled
> "Illustrative demo pricing — not market verified." No supplier, OEM or insurer price has been
> verified for this project.

## Pricing coverage today

- **Hyundai i20, 2020–2024**: panels, lamps, glass, mirrors, tyres (region `IN-DEMO-METRO`, INR, excl. GST).
- **Hyundai i20, 2015–2019**: front bumper only (used by applicability tests).
- **Maruti Suzuki Swift, 2018–2023**: front bumper and left headlight only.
- Not covered: side windows, component `other`, every other vehicle/year. These return
  `insufficient_pricing_data` (cost unknown, **never zero**).

## Record format (`pricing_records_*.csv`)

One row per (vehicle range, component, operation, part grade). Numeric columns are the **only**
input to arithmetic; the prose columns are used for semantic ranking and explanations.

| Column | Rules |
|---|---|
| `record_id` | Unique across all CSV files. |
| `source_id` | Must exist in `sources.json`. |
| `make`, `model`, `variant` | `variant=all` applies to every trim. |
| `year_from`, `year_to` | 1980–2100, `year_from <= year_to`. |
| `component` | A name from `src/vocab.py` (`other` is rejected). |
| `position` | `any` only with a family name (e.g. `side_mirror`) to cover left and right. |
| `operation` | `refinish`, `repair` or `replace`. |
| `part_grade` | `oem`, `aftermarket` or `n/a`. |
| `parts_cost_low/high`, `labor_hours_low/high`, `labor_rate_low/high`, `paint_materials_low/high` | Non-negative, low ≤ high. |
| `currency` | ISO code, e.g. `INR`. |
| `region` | e.g. `IN-DEMO-METRO`, `IN-DEMO-TIER2`. |
| `tax_included` | `true`/`false`. Mixed tax treatment is never summed silently. |
| `data_quality` | `synthetic_demo` (only in `*_demo.csv`), `sourced_unverified`, `sourced_verified`. |

Line cost (Decimal, whole rupees, ROUND_HALF_UP):

```
low  = parts_cost_low  + labor_hours_low  * labor_rate_low  + paint_materials_low
high = parts_cost_high + labor_hours_high * labor_rate_high + paint_materials_high
```

## Adding genuine prices

1. Add the source to `sources.json` with a real, checkable `reference` (quote number, document,
   URL) and a `source_type` other than `synthetic_demo` (`published_price_list`, `dealer_quote`,
   `workshop_estimate`, `insurer_schedule`, `other_documented`).
2. Add rows to `pricing_records_sourced.csv` with `data_quality=sourced_unverified`
   (or `sourced_verified` once independently checked). Never invent supplier URLs or quotes.
3. Validate: `python -m src.kb.build_index --check`
4. Rebuild the index: `python -m src.kb.build_index` (the app also rebuilds automatically when
   it detects changed records - the corpus hash is stored with the index).
5. Run `python -m pytest` and `python scripts/smoke_check.py`.

## Retrieval in one paragraph

Hard filters (never relaxed): currency, region, make (alias-normalised), model, component
instance, operation. Then explicit, labelled fallback levels: `L0_exact` → `L1_grade_relaxed` →
`L2_year_unverified` (no year given) → `L3_broader_reference` (other model years, only when
explicitly allowed). Inside a level, candidates are ranked by cosine similarity of
`sentence-transformers/all-MiniLM-L6-v2` embeddings. A different make/model is never substituted.
